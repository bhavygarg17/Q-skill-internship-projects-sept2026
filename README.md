QSkill Python Internship Projects 🚀

This repository contains three Python projects developed as part of the QSkill Python Internship.

Projects

1. Data Analysis using Pandas

- Load and analyze the Iris dataset.
- Calculate statistical summaries and average values.
- Create bar charts, scatter plots, and a correlation heatmap.
- Libraries: Pandas, Matplotlib.

2. House Price Prediction

- Predict house prices using Linear Regression.
- Preprocess numerical and categorical data.
- Evaluate the model using MAE and R² score.
- Libraries: Pandas, NumPy, Scikit-learn.

3. Matrix Operations using NumPy

- Perform matrix addition and subtraction.
- Perform element-wise multiplication.
- Calculate matrix transpose and determinant.
- Library: NumPy.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

How to Run

Install the required libraries:

pip install pandas numpy matplotlib scikit-learn

Run a project using Python:

python data_analysis.py
python house_price_prediction.py
python matrix_operations.py
